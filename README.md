# Планировщик натяжных потолков

Веб-приложение для создания проектов натяжных потолков с чертежами, спецификацией оборудования и экспортом документов.

## Структура приложения

Программа представляет собой одностраничное веб-приложение (SPA) на чистом JavaScript без сборки:

- **index.html** - основной файл, содержащий HTML, CSS и JavaScript
- **koorti_28-61.json** - пример сохраненного проекта

### Основные компоненты:

1. **Интерфейс проекта**
   - Боковая панель с настройками проекта и комнат
   - Canvas для визуального редактирования чертежей
   - Спецификация оборудования с ценообразованием

2. **Функциональность**
   - Создание нескольких комнат в одном проекте
   - Добавление элементов: точечные светильники, трековые системы, люстры, карнизы, вентиляция, обход труб
   - Формы комнат: прямоугольник, Г-образная, П-образная, Т-образная
   - Подсветка по периметру и в карнизах
   - Перетаскивание элементов мышью

3. **Экспорт**
   - PDF с чертежами и спецификацией (библиотека jsPDF)
   - JPEG для каждой комнаты
   - Excel со списком оборудования (библиотека SheetJS)

4. **Распознавание по фото**
   - Автоматическое распознавание чертежей через API Anthropic Claude
   - Требуется API-ключ (хранится только в браузере)

5. **Хранение данных**
   - LocalStorage для автоматического сохранения
   - Экспорт/импорт проектов в JSON
   - Резервные копии всех проектов

## Как запустить

### Вариант 1: Прямое открытие в браузере (рекомендуется)

Просто откройте файл `index.html` в любом современном браузере:

```bash
open index.html
```

Или перетащите файл в окно браузера.

### Вариант 2: Локальный сервер

Для корректной работы некоторых функций (особенно при разработке) можно использовать локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (если установлен npx)
npx serve
```

Затем откройте в браузере: `http://localhost:8000`

## Требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет-соединение для загрузки библиотек (jsPDF, SheetJS) и распознавания по фото
- API-ключ Anthropic для функции распознавания (опционально)

## Формат данных проекта

Проекты сохраняются в формате JSON со следующей структурой:

```json
{
  "id": "уникальный_id",
  "name": "Название проекта",
  "status": "Замер|Предложение|Согласован|Монтаж|Готово",
  "dm": "дата замера YYYY-MM-DD",
  "di": "дата монтажа YYYY-MM-DD",
  "t1": "время начала HH:MM",
  "t2": "время окончания HH:MM",
  "client": {
    "n": "имя заказчика",
    "p": "телефон",
    "e": "email",
    "a": "адрес"
  },
  "rooms": [
    {
      "id": "id комнаты",
      "name": "Название комнаты",
      "pts": [[x1,y1],[x2,y2],...], // координаты углов в см
      "perim": {"on": true, "w": 4, "col": "#ffc94d"},
      "mat": {"brand": "MSD", "tex": "матовая", "color": "белый"},
      "items": [...] // элементы комнаты
    }
  ]
}
```

## Примечания

- Все данные хранятся локально в браузере (LocalStorage)
- Для сохранения данных между браузерами используйте функцию экспорта/импорта
- Библиотеки загружаются из CDN при наличии интернета
- При отсутствии интернета программа работает, но экспорт в PDF/Excel недоступен
